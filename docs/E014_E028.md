# E014–E028: text ensemble, audio channels, calibration and unseen-speaker validation

All experiments keep the E008 population (732 rows with `label > 0`) and the five
frozen folds, so OOF metrics are directly comparable with E008. A candidate is
accepted only if it improves pooled OOF RMSE and at least four of five folds.
Public leaderboard scores were recorded but never used for selection.

## E014: parameterized fine-tuning and seed ensembles

`experiments/e014_finetune.py` makes backbone, seed and optimizer settings explicit
(E008's protocol was frozen). Changes from E008: encoder dropout off, regression head
initialized at the training-fold mean with its own learning rate (1e-3), optional
layer-wise LR decay, max length 320, optional LoRA/QLoRA, gradient checkpointing and
dual-transcript training. Epoch selection per fold on validation RMSE is unchanged;
`prediction_last` columns record selection-free last-epoch predictions.

- DeBERTa-v3-base ×3 seeds: 0.5921 OOF RMSE (seed mean ensemble).
- DeBERTa-v3-large, lr 1e-5, layer decay 0.9, ×4 seeds: 0.5808.
- Equal-weight base + large: **0.5732 / 0.8250** (E008: 0.6198 / 0.7942).
- OOF linear calibration did not help (head initialization already calibrates).

## E015: verbatim ASR

`transcription/verbatim.py` decodes with faster-whisper large-v3 and a disfluent
prompt. Variant `v1` conditions on previous text; variant `v2` disables conditioning,
passes a short disfluent `hotwords` cue that faster-whisper inserts into every
window, and lowers the compression-ratio threshold to 2.0.

| Train split | canonical | v1 | v2 |
| --- | ---: | ---: | ---: |
| fillers per file | 0.37 | 4.67 | 4.08 |
| false starts per file | 0.00 | 1.88 | 1.52 |
| prompt-leak files | 0 | 1 | 0 |
| repetition-loop files | 0 | 6 | 4 |

Same-seed comparisons (OOF RMSE):

| Model | canonical | v1 | v2 | dual (canonical + v1) |
| --- | ---: | ---: | ---: | ---: |
| base, seed 42 | 0.6021 | 0.5918 | 0.5929 | 0.5787 |
| base, seed 7 | 0.6056 | 0.5976 | 0.5931 | 0.5848 |
| large, seed 42 | 0.5842 | 0.5875 | 0.5762 | 0.5685 |
| large, seed 7 | 0.6011 | 0.5956 | 0.5785 | 0.5882 |

Final ensemble: equal-weight mean of four seed-averaged groups — large dual ×3,
base dual ×3, large v2 ×2, base v2 ×2 — **OOF RMSE 0.5545, Pearson 0.8372**; all
five folds improve over the previous best (0.5603). Public LB 0.3778.

## E020: literal CTC transcripts (final)

`transcription/ctc.py` transcribes with `facebook/wav2vec2-large-960h-lv60-self`
(greedy CTC, 20 s chunks with 4 s overlap, lower-cased, no punctuation). Test
transcripts are all non-empty; 17 training transcripts are empty and all belong to
the excluded zero-label block. CTC rarely writes fillers (0.24 per 100 words, trained
on read speech) but keeps literal word errors.

| Model on CTC | seed 42 | seed 7 |
| --- | ---: | ---: |
| DeBERTa-base | 0.6135 | 0.6240 |
| DeBERTa-large | 0.6005 | 0.5898 |

Adding the two CTC groups to the E015 ensemble (six equal-weight groups) gives
**OOF RMSE 0.5466, Pearson 0.8426**, improving all five folds (−0.0015, −0.0006,
−0.0195, −0.0171, −0.0033). Correlation between the CTC-large group and the previous
final ensemble is 0.933. Public LB 0.3712 (best). Trained on Colab
(`e020_ctc_colab.ipynb`); results in the private dataset
`lijoraju94/grammar-scoring-ctc-results`.

## E022: WavLM audio channel (final)

`experiments/e022_audio.py`. Frozen `microsoft/wavlm-base-plus` embeddings from
`features/wavlm.py` (train: cached E009 extraction; test: same code on Colab, five
re-extracted training files match the cache at cosine 1.0000). Standardized RBF-SVR
with `C` ∈ {1, 3, 10, 30} and `epsilon` ∈ {0.05, 0.2} chosen by an inner 4-fold CV
inside each outer training fold; audio weight chosen per outer fold on the other
folds (0.45, 0.45, 0.40, 0.40, 0.40) and on all OOF predictions (0.40).

| Model (frozen folds) | OOF RMSE | Pearson |
| --- | ---: | ---: |
| E009 WavLM + Ridge(alpha=1) | 0.8998 | 0.643 |
| WavLM + Ridge(alpha=1000) | 0.6299 | 0.786 |
| WavLM + RBF-SVR, nested | 0.5858 | 0.817 |
| E020 text ensemble | 0.5466 | 0.843 |
| **E022 = 0.6 text + 0.4 audio, nested** | **0.5073** | **0.872** |

All five folds improve over E020 (by 0.023–0.058). Public LB 0.3605 (E020: 0.3712);
one submission at the CV-chosen weight, no weight tuned on the leaderboard (a second,
package-reproduced file differing by ≤1.7e-4 also scored 0.3605).

Batch-effect checks: labels of adjacent file IDs correlate 0.514. With fixed SVR
settings, audio-only RMSE is 0.598 on random folds and 0.664 / 0.679 / 0.719 with
folds grouped by 25 / 50 / 100-ID blocks; a text stand-in (frozen DeBERTa embeddings
+ the same SVR) goes 0.627 → 0.639 / 0.647 / 0.654, and a 50/50 audio-text blend still
beats the text stand-in under every grouping (0.626 vs 0.654 at 100-ID blocks). A
train-vs-test audio classifier reaches AUC 0.76–0.82 depending on the split. Part of
the audio CV gain is batch recognition, so 0.507 is optimistic for new recording
sources.

## E023: stronger audio encoders (rejected)

`features/audio_layers.py` stores per-layer mean and standard deviation over all
valid frames for WavLM-base-plus, WavLM-large and the Whisper large-v3 encoder
(Colab; WavLM-base last-layer means reproduce E009 at cosine 1.0000). Fixed-SVR
layer screens show middle/upper layers beat the last layer (WavLM-base last layer
0.598, layers 7–10 about 0.565; WavLM-large layers 13–22 about 0.55); standard
deviations add little. Selection-free all-layer averages, nested SVR:

| Audio (nested SVR) | Audio OOF | Text + audio, nested blend |
| --- | ---: | ---: |
| E022 WavLM-base last layer | 0.5858 | 0.5073 |
| WavLM-base all-layer mean | 0.5507 | — |
| WavLM-large all-layer mean | 0.5392 | 0.4886 |
| Whisper large-v3 encoder all-layer mean | 0.5387 | 0.4846 |
| mean of WavLM-large and Whisper | 0.5211 | **0.4809** |

Under 100-ID grouped folds the averaged audio scores 0.654 (E022 audio 0.719), so
it is also better on held-out batches. With a 0.55 audio weight the single public
check scored 0.3649, worse than E022 (0.3605). Rejected; no weights were tried on
the leaderboard.

## E024: cross-fitted calibration of the E022 blend (final)

`e022_audio.calibrate_oof` / `calibrate_test` (CLI `--calibrate`). Averaging text and
audio shrinks predictions; per-fold lines fitted on the other folds have slopes
1.124–1.151 and intercepts −0.43 to −0.54. Cross-fitted calibration plus clipping to
[1, 5] gives **OOF RMSE 0.4942, Pearson 0.8734** (E022: 0.5073 / 0.8720), improving
every fold (−0.014, −0.016, −0.004, −0.011, −0.019). Test line: −0.4799 + 1.1351 ×
blend (11 test predictions clipped at 5). Public LB **0.3501** (one submission). The
same calibration on E023 gave OOF 0.4669 but was not submitted, since E023 had
already failed its public check.

## E025–E027: test mix, speakers and honest validation (final)

Prompted by a public top solution, three properties of the data were checked.

**Test mix.** Recordings shorter than 50 s are 24% of the 732 training rows and 69% of
the test set (a 45.06 s batch alone is 11% vs 39%) and score lower (mean 3.13 vs 3.59).
E024's random-fold RMSE is 0.551 on short and 0.474 on long clips; its SVR audio
channel scores 0.706 on short clips.

**E025 (rejected).** E023 audio with blend weight and calibration fitted per duration
batch (short: 0.30 audio, long: 0.65). Random-fold test-mix RMSE 0.4967 (E024: 0.5285),
all five folds better, but public LB 0.3499 (E024: 0.3501).

**Speakers.** x-vectors (`microsoft/wavlm-base-plus-sv`, unit mean of 10 s windows,
centred on the train+test mean) linked at cosine > 0.93 give 377 speakers for 732
clips; 69% of clips have a same-speaker partner, within-speaker label spread is 0.19
(overall 1.01), and 13% of test clips match a training speaker. Random-fold RMSE by
whether the clip's speaker is also in the training folds:

| | speaker seen (477) | speaker unseen (255) |
| --- | ---: | ---: |
| text ensemble | 0.521 | 0.591 |
| E022 audio (RBF-SVR, WavLM-base last layer) | 0.495 | 0.726 |
| E024 | 0.445 | 0.575 |

**Speaker-grouped CV of frozen-feature channels (all 732 rows):** WavLM-base last layer
SVR 0.652; WavLM-large all-layer mean SVR 0.623; WavLM-large layer 20 Ridge(α=1000)
0.582; Whisper-encoder layers 22–32 Ridge(α=1000) 0.575; Voxtral-Mini-3B layers 12–14
Ridge(α=3000) 0.553 (α 300/1000/10000: 0.581/0.556/0.580; single layers 0.552–0.584).
Up-weighting short clips in the audio regressors did not help.

**Honest test-mix RMSE on the 255 unseen-speaker rows** (weights and calibration nested
over folds): text 0.590; E024 0.579; text + E022 audio refitted honestly 0.572;
**E026** text + Ridge audio (WavLM-large L20, Whisper L22–32) 0.549, public LB 0.3448;
text + Voxtral 0.552; **E027** text + audio + Voxtral **0.544** (4 of 5 folds better
than E026), weights 0.40 / 0.30 / 0.30, line −0.4414 + 1.1094 × blend, public LB
**0.3362**. A different speaker-grouped fold assignment gives 0.553 and weights
0.45 / 0.30 / 0.25, so the estimate carries about ±0.01 of noise. All six text groups
score 0.60–0.65 on unseen speakers and their equal-weight mean is best (0.590).

**Left out on purpose.** For training rows with a same-speaker clip in other folds,
mixing in that speaker's known label lowers RMSE from 0.48 to 0.39; only 5–13% of test
clips have such a match, and it is speaker recognition rather than grammar scoring.

## E028: speaker-grouped text models and Voxtral views (final)

**Text retrained on speaker-grouped folds.** Five stratified folds with every
speaker's clips in one fold (141–148 rows, mean label 3.46–3.50;
`train_folds_grouped.csv`, `e014_finetune --folds-csv`). Per-run OOF RMSE: large dual
0.580 / 0.579 / 0.587, base dual 0.583 / 0.597 / 0.594, large v2 0.586 / 0.582, base v2
0.601 / 0.588, large CTC 0.610 / 0.602, base CTC 0.617 / 0.618; six-group ensemble
0.5499 (random folds: 0.5466). On the 477 rows whose speaker was also in the random
training folds, random-fold vs speaker-grouped models score 0.5213 vs 0.5258; on the
other 255 rows 0.5909 vs 0.5922. Text models barely use speaker identity; the 255 rows
are mostly single-clip speakers, which are harder (text RMSE 0.605 vs 0.523).

**Test mix, second factor.** 29% of test clips have another test clip by the same
speaker (training: 69%); short clips from single-clip speakers are 62% of test and 18%
of training. Weights match the four (short, partner) cells to the test set.

**Voxtral views.** Three questions placed after the audio give bit-identical audio-token
states (the model reads left to right). With the question first, layers 12–14 Ridge
(α = 3000), speaker-grouped RMSE: audio-first 0.5585, grammar question first 0.5588,
errors question first 0.5544; final-token states 0.59–0.61 (rejected). Channel = mean
of the three audio-token views.

**Blend on all 732 rows** (nested over the speaker-grouped folds, weighted to the test
mix): text 0.5736, audio 0.6028, Voxtral 0.5603, blend **0.5356** (unweighted 0.5212,
Pearson 0.859; folds 0.480–0.556); weights 0.35 / 0.25 / 0.40, line −0.3849 + 1.0985 ×
blend. Against the same blend with only the audio-first Voxtral view: −0.0044, all five
folds better. E027's fixed formula applied to these predictions scores 0.5326, i.e. the
two are within noise; the public LB moved from 0.3362 to **0.3341**.

**Explicit features re-tested** with unseen-speaker validation (GEC edit rate, LLM
rubric judge, fluency features; Ridge or gradient boosting): channel RMSE 0.71–0.74,
zero blend weight. Rejected again.

## Rejected

- **E016** Qwen2.5-7B, 4-bit QLoRA r=16, lr 1e-4, 3 epochs: 0.7095 / 0.7370 (still
  improving at the last epoch, 102 GPU-minutes); a 10% blend was within noise.
- **E017** (`features/grammar_signals.py`, `experiments/e017_stack.py`): CoEdIT GEC
  edit rate and a zero-shot Qwen2.5-7B-Instruct rubric judge. Edit rate correlates
  −0.49 with the label but ≈0 with ensemble residuals; stacking gain ≤0.003.
- **E019** (`features/disfluency.py`): filler, false-start, repetition, ASR-repair,
  lexical and timing features. Only word count correlated with residuals (+0.14);
  stacking it gave 0.5642 vs 0.5680 but improved only 3 of 5 folds.

- **E021** RoBERTa-large (`FacebookAI/roberta-large`) dual canonical + verbatim v1,
  lr 1e-5, layer decay 0.9, seeds 42 and 7 (Colab `e021_roberta_colab.ipynb`): each seed
  0.5828 / 0.818; group 0.5754 (DeBERTa-large dual: 0.5704). As a seventh equal-weight
  group: 0.5443 / 0.8442 vs E020 0.5466, but only 3 of 5 folds improve (fold deltas
  −0.0028, −0.0050, +0.00002, +0.0015, −0.0042), so it fails the gate.
- **Post-processing:** rounding to the 0.5 label grid worsens every fold (0.5732);
  clipping to [0, 5] only affects predictions above 5 and changes OOF RMSE by 0.0004.
- **Tree models** (scikit-learn gradient boosting and random forest) on hand-crafted
  features score about 0.82; as stackers over the group predictions, with or without
  features, they are worse than equal weighting (0.559–0.589), as is a Ridge stacker
  (0.5494).

- **Test-time audio normalization** (align held-out embeddings to the training mean,
  optionally also the spread) to counter recording-batch shift. Fixed-SVR audio RMSE,
  random / 25-ID / 100-ID grouped folds: E022 audio 0.598 / 0.664 / 0.719 as is vs
  0.601 / 0.711 / 0.813 centred; E023 audio 0.532 / 0.606 / 0.654 vs 0.535 / 0.661 /
  0.748. Held-out fold mean labels vary by 0.26–0.35 under grouping (0.04 random), so
  batch differences partly reflect real speaker ability and centring removes it.
  Rejected without a leaderboard submission.

Stacking protocols (E017, E019) are cross-fitted over the frozen folds but are not
nested CV: OOF predictions of training rows come from fold models that saw the
validation fold.
