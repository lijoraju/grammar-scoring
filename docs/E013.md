# E013: ASR-Aligned Fluency Features

Final modeling experiment: test whether temporal structure and disfluency in
canonical Whisper transcripts complement E008. No new ASR, audio processing,
model variants, tuning, test predictions, or submissions are performed.

## Frozen inputs and protocol

The E008 OOF CSV supplies filename, label, fold, and prediction: exactly 732
unique rows with positive labels and all five integer folds 0..4. Rows join by
filename and preserve E008 order and folds. The canonical train JSONL contains
filename, split, language, text, duration_seconds, and segments; each segment
requires numeric finite start/end and string text. Extra training transcripts
outside E008 are permitted but never enter fitting. Duplicate filenames,
missing records/fields, invalid population/folds, and nonfinite features fail.

Exactly two candidates run on CPU. Each fold fits a fresh StandardScaler only
on the 19 feature columns outside that fold, followed by Ridge(alpha=1.0) with
default solver and intercept. E013-residual fits label minus existing E008 OOF
prediction and adds its correction to the unchanged E008 validation prediction.
E013-stack fits labels using raw E008 prediction as its first design column,
followed by scaled features. Predictions are never clipped or calibrated. Seed
42 is recorded; the estimators use no random sampling.

As in E012a, this prescribed protocol is not nested cross-validation. E008 OOF
predictions for downstream training rows may depend on labels in the downstream
validation fold. Downstream scalers and Ridge models exclude that fold, but the
inherited dependency remains when interpreting results. E008 is unchanged.

## Exact feature schema (19 columns, in order)

1. segment_count
2. words_per_segment_mean
3. words_per_segment_std
4. segment_duration_mean
5. segment_duration_std
6. short_segment_ratio
7. recognized_speech_seconds
8. speech_coverage_ratio
9. words_per_recognized_speech_second
10. gap_count
11. gap_mean
12. gap_std
13. gap_max
14. total_gap_seconds
15. long_gap_0_5_count
16. long_gap_1_0_count
17. long_gap_2_0_count
18. filler_rate
19. immediate_repetition_rate

Tokenization lowercases and extracts ASCII alphabetic tokens with `[a-z]+` for
both segment text and final text. Segment word counts use each segment's text;
speech rate and disfluency use final text. Fillers are exactly um, uh, erm, hmm.
Immediate repetition counts adjacent identical pairs divided by max(words-1, 1).

Segment duration is max(0, end-start). Short means strictly less than 2 seconds.
Recognized speech sums segment durations without merging overlaps; coverage is
that sum divided by recording duration and can exceed one. Gaps follow artifact
segment order and equal max(0, next.start-current.end). gap_count includes zero
gaps; threshold counts use >= 0.5, >= 1.0, and >= 2.0 seconds. Standard deviations
use ddof=0. Empty statistics, fewer-than-two standard deviations, and ratios
with zero denominators return zero. All feature values are finite floats.

## Reports and frozen decision gate

metrics.json reports pooled and per-fold RMSE and Pearson for E008 and both
candidates. diagnostics.json reports candidate-minus-E008 deltas, counts of
folds improving each metric, prediction correlation, correlation between the
two label-minus-prediction residual vectors, and strict absolute-error win rate
(ties are not wins). True-label score bands are low <3, mid 3<=label<4, high >=4,
with n, baseline/candidate metrics and RMSE delta. Undefined correlations and
empty-band metrics serialize as null.

A candidate is marked compelling exactly when pooled RMSE <=0.58, pooled
Pearson >=0.7942308488890498, and RMSE improves in at least four of five folds.
The gate triggers no further actions. The report also records deviations from
the supplied E008 reference, warning when either metric differs by >0.01.

config.json records input paths and SHA256 hashes, ordered features and their
conventions, filename/fold identities, population, scaling, seed and Ridge
settings. Outputs are gitignored:

- artifacts/oof/E013_residual.csv
- artifacts/oof/E013_stack.csv
- artifacts/experiments/E013/config.json
- artifacts/experiments/E013/metrics.json
- artifacts/experiments/E013/diagnostics.json

The optional feature CSV is not persisted; features are cheap to reconstruct
from the hashed source. Existing outputs require --overwrite.

## Kaggle CPU command

From the repository root, using the existing Kaggle environment dependencies,
replace the two input mount paths with the locations of your uploaded artifacts:

```sh
PYTHONPATH=src python scripts/run_asr_fluency_residual.py \
  --e008-oof /kaggle/input/e008-oof/E008_deberta_no_zero_block.csv \
  --transcripts /kaggle/input/whisper-transcripts/train.jsonl \
  --artifact-dir /kaggle/working/artifacts
```

No new dependencies or GPU are required. Defaults use GRAMMAR_ARTIFACT_DIR
(or the repository artifacts directory). The local E008 OOF artifact is absent,
so no real E013 metrics are reported; synthetic tests are not modeling results.

```sh
.venv/bin/pytest tests/features/test_asr_fluency.py tests/experiments/test_asr_fluency_residual.py
.venv/bin/pytest
.venv/bin/ruff check .
.venv/bin/ruff format --check .
```
