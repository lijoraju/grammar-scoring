# E012a: acoustic residual correction of E008

This cheap CPU diagnostic asks whether the existing 51 E006a descriptors explain
E008's remaining OOF error. E006a predicted the grammar target independently,
then searched weighted score blends with E005. Those promising offline fusion
results transferred poorly to the leaderboard. E012a instead protects the E008
prediction with coefficient one and predicts its remaining error:
`residual_target = label - e008_prediction`. A fixed linear stack is the control.

## Fixed protocol

The E008 OOF CSV is authoritative for the retained population and assignments:
exactly 732 unique positive-label rows, with all integer folds 0..4 present.
There is no filename-ID filtering or fold regeneration. The artifact must be
actual E008 OOF predictions, never in-sample predictions. A CSV alone cannot
prove the training provenance of its predictions; supplying the correct existing
E008 output is an input requirement.

E006a's acoustic CSV has the exact ordered schema `filename`, `split`,
`duration_seconds`, followed by the 51 canonical `FEATURE_COLUMNS`. It contains
769 training rows; extra rows outside E008 are allowed and never enter fitting.
Alignment uses filename, regardless of either input's row order, and preserves
E008 input order. Duplicate identities, missing rows, invalid labels/folds,
nonfinite values, unexpected splits or feature schemas fail loudly. Duration is
validated audit metadata and excluded from the model matrix. No test files load.

For each existing fold k, a fresh StandardScaler fits only the 51 acoustic
columns on rows outside k. Ridge(alpha=1.0), with sklearn's default solver and
intercept, fits the scaled training acoustics to E008 residuals. Its validation
correction is added to the unchanged E008 OOF prediction. The stack control fits
a separate fold-local scaler and Ridge to the original label, with 52 columns:
raw E008 prediction first, followed by scaled acoustics. The E008 prediction is
never standardized. Seed 42 is recorded; these estimators use no random sampling.
All outputs are raw: no selection, tuning, weighting, calibration or clipping.

The scaler and downstream Ridge never fit on their validation fold. As with
E011a's requested protocol, this is not nested cross-validation: E008 predictions
for downstream training rows in other folds can depend on labels from the
current downstream validation fold. The prescribed protocol is unchanged;
interpret the resulting OOF estimate with that dependency in mind.

## Reports and interpretation

Metrics contain pooled/per-fold RMSE and Pearson for E008, E012a-residual and
E012a-stack. Diagnostics compare each candidate against the exact aligned E008:
candidate-minus-E008 metric deltas, improving fold counts, prediction and
label-minus-prediction residual correlations, and lower absolute error counts
and percentages. Fixed true-label bands are low <3, mid 3<=label<4, high >=4,
with counts, paired metrics and mean predictions. Undefined correlations become
JSON null; empty bands retain n=0 and null metrics/means.

All 51 feature correlations with E008 residuals are computed on the full aligned
population for diagnostics only. The ten highest absolute correlations and all
ten temporal/activity correlations are reported. Neither ranking selects features.
An absolute deviation >0.01 from either supplied E008 reference (RMSE 0.619789,
Pearson 0.794231) warns and is recorded without changing behavior.

A compelling continuation guideline is RMSE <=0.59, Pearson at least E008's,
and RMSE improvement in at least four of five folds. It is not model logic and
this experiment alone does not justify a leaderboard submission.

## Run and artifacts

From the repository root, with the existing artifacts present:

```sh
.venv/bin/python scripts/run_acoustic_residual.py
```

For artifacts stored elsewhere:

```sh
.venv/bin/python scripts/run_acoustic_residual.py \
  --e008-oof /path/to/E008_deberta_no_zero_block.csv \
  --acoustic-path /path/to/acoustic_train.csv \
  --artifact-dir artifacts
```

Defaults honor `GRAMMAR_ARTIFACT_DIR`. Existing outputs require `--overwrite`.
No new dependencies, acoustic extraction, model downloads or GPU are required.

- `artifacts/oof/E012a_residual.csv`
- `artifacts/oof/E012a_stack.csv`
- `artifacts/experiments/E012a/config.json`
- `artifacts/experiments/E012a/metrics.json`
- `artifacts/experiments/E012a/diagnostics.json`
- `artifacts/experiments/E012a/residual_feature_correlations.csv`

OOF outputs include filename, label, fold, e008_prediction, prediction, residual
(label minus candidate prediction), abs_error; residual output also includes
predicted_correction. Configuration and diagnostic provenance record both input
paths/SHA256 hashes, feature order, full filename/fold identity, population rule,
alpha, scaling, solver and seed. Generated artifacts remain gitignored.

The local acoustic artifact has the documented 769-row E006a schema. The expected
