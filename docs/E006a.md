# E006a: interpretable acoustic/prosodic Ridge baseline

Research question: does the waveform contain useful grammar-score signal, and
is it complementary to the E005 transcript model?

## Reproduce

```bash
uv run python scripts/generate_acoustic_features.py
uv run python scripts/run_acoustic_baseline.py
```

Both commands refuse to overwrite their own existing outputs unless supplied
`--overwrite`. They never create folds, test predictions, or submissions.
Extraction metadata records every WAV's SHA256, validated audio properties,
configuration, feature order, extraction source hashes, and runtime. Experiment
configuration records frozen fold, E005, and feature-artifact hashes. Generated
artifacts stay under the repository's ignored `artifacts/` directory.

## Fixed methodology

Canonical PCM16 WAVs must be readable, nonempty, finite, mono, and 16 kHz;
truncated samples or unexpected formats fail. Integer samples are decoded to
floating-point PCM amplitude by division by 32768. There is no resampling,
mixing, denoising, trimming, or amplitude normalization.

The 51 predefined model features comprise 10 activity/pause summaries, seven
energy summaries, eight zero-crossing/spectral summaries, and 26 MFCC summaries.
Raw duration is audit metadata only, and sample count is never predictive input.
No labels or transcripts enter extraction. No feature selection or alpha tuning
is performed; all predefined finite features are retained regardless of shift.

Complete 25 ms frames advance every 10 ms. Short files use their available
samples; trailing incomplete frames are ignored in frame summaries. A frame is
active when RMS exceeds `max(1e-5, 0.1 * file RMS 90th percentile)`. This is an
energy detector, not a phonetic voicing detector. Internal inactive runs of at
least 200 ms count as pauses; leading/trailing silence does not count as a pause.
Segment durations are frame counts times 10 ms. No pauses or no activity yield
zero pause/segment summaries, avoiding undefined divisions.

Energy summaries use unwindowed RMS. Spectral summaries use Hann-windowed
512-point FFT power over all frames. Centroid and bandwidth use power weights;
rolloff uses 85% cumulative power. Silent frames have zero spectral moments.
MFCCs use 26 triangular HTK mel filters from 0 to 8 kHz, natural log power floored
at 1e-12, and orthonormal DCT-II coefficients 0..12. Artifact names 01..13 refer
to these 13 coefficients, including the zeroth coefficient. Only coefficient
means and population standard deviations are retained. F0 is omitted because
a reliable pitch implementation is absent from the existing dependencies;
custom pitch DSP is beyond this deliberately simple baseline.

Each existing frozen fold gets a fresh `StandardScaler` followed by
`Ridge(alpha=1.0, solver="lsqr")`. Both fit only that fold's training rows.
Labels, feature identities, and frozen folds align by filename, never row
position. Predictions are unclipped. Diagnostic training RMSE pools all fold
training predictions, matching earlier experiments. Seed 42 documents the
frozen fold convention; extraction and the estimator use no random operations.

Signed SMD is `(test_mean - train_mean) / sqrt((train_var + test_var) / 2)` with
population variances. Absolute SMD at least 0.5 is moderate, at least 0.8 large.
Equal constants have zero SMD; unequal constants have signed infinite SMD and
are flagged large. Undefined Pearson values serialize as JSON null.

Blends use E005 weights 0.50..1.00 in increments of 0.05. Every candidate has
pooled and per-fold metrics, fold improvement counts, and worst-fold deltas.
RMSE delta is blend minus E005 (positive is worse); Pearson delta is also blend
minus E005 (negative is worse). Best grid weights are exploratory OOF selections,
not independently validated or nested-CV estimates of fusion performance.

## Limitations

Background noise can register as speech activity. Frame-grid pauses approximate
energy interruptions, not linguistic pauses. Acoustic descriptors can capture
recording conditions, speaker properties, or task structure rather than grammar.
Pause counts and maxima can retain indirect length dependence even though raw
duration and sample count are excluded. Silence and near-zero energy ratios
have documented finite defaults. Distribution shifts are diagnostics, not proof
of invalidity or evidence that filtering improves generalization. There is no
leaderboard tuning and no claim that an OOF blend will improve a leaderboard.

## Local results

Full extraction took **199.997 seconds** for 769 train and 216 test WAVs,
producing **51** finite canonical model features. No dependencies were added.
The focused tests passed **31/31**; the full suite passed **526/526**.
`uv run ruff check .` and `uv run ruff format --check .` passed. The full suite
emits one pre-existing PyTorch/NumPy compatibility warning; E006a uses neither
PyTorch nor pretrained models.

E006a pooled OOF **RMSE 0.868546**, **Pearson 0.714764**. Diagnostic pooled
fold-training RMSE is **0.800810**. The aligned E005 reference is RMSE 0.835248,
Pearson 0.741944. Acoustic features have substantial standalone predictive
signal on these folds, although their pooled metrics trail E005.

retained as predefined, with its possible indirect length dependence explicit.
